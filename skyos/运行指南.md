# SkyOS Flutter 应用运行指南

## 方式一：在本地运行（推荐）

### 1. 安装 Flutter

如果您还没有安装 Flutter，请按照以下步骤：

**macOS 安装步骤：**

1. 下载 Flutter SDK：
   ```bash
   # 使用 Homebrew 安装（推荐）
   brew install --cask flutter
   
   # 或者手动下载
   # 访问 https://flutter.dev/docs/get-started/install/macos
   ```

2. 验证安装：
   ```bash
   flutter doctor
   ```

3. 安装 Xcode（用于 iOS 开发）：
   ```bash
   # 从 App Store 安装 Xcode
   # 然后运行：
   sudo xcode-select --switch /Applications/Xcode.app/Contents/Developer
   sudo xcodebuild -runFirstLaunch
   ```

### 2. 运行应用

在项目目录下执行：

```bash
# 1. 进入项目目录
cd /Users/eliza/skyos

# 2. 安装依赖
flutter pub get

# 3. 检查可用设备
flutter devices

# 4. 运行应用
flutter run
```

### 3. 运行平台选择

- **iOS 模拟器**（macOS）：
  ```bash
  # 打开 iOS 模拟器
  open -a Simulator
  
  # 然后运行
  flutter run
  ```

- **Android 模拟器**：
  ```bash
  # 需要先安装 Android Studio
  # 然后创建并启动 Android 模拟器
  flutter run
  ```

- **物理设备**：
  - iOS：连接 iPhone，在 Xcode 中信任设备
  - Android：启用 USB 调试，连接设备

## 方式二：使用在线 Flutter 预览工具

如果您想快速预览，可以使用在线工具：

1. **Flutter Web**（如果支持）：
   ```bash
   flutter run -d chrome
   ```

2. **DartPad**（仅限简单代码，此项目较复杂，可能不支持）

## 方式三：使用 VS Code 或 Android Studio

### VS Code：
1. 安装 Flutter 和 Dart 扩展
2. 打开项目文件夹
3. 按 `F5` 或点击运行按钮

### Android Studio：
1. 安装 Flutter 插件
2. 打开项目
3. 点击运行按钮

## 常见问题

### Flutter 命令未找到
确保 Flutter 已添加到 PATH：
```bash
export PATH="$PATH:`pwd`/flutter/bin"
# 或添加到 ~/.zshrc
echo 'export PATH="$PATH:/path/to/flutter/bin"' >> ~/.zshrc
source ~/.zshrc
```

### 依赖安装失败
```bash
flutter clean
flutter pub get
```

### 设备未识别
```bash
flutter doctor -v
# 根据提示修复问题
```
