# 在移动设备上运行 SkyOS 应用

## 方法一：在浏览器中查看移动效果（当前可用）

应用已在 Chrome 中运行，您可以：

1. **打开 Chrome 开发者工具**
   - 按 `F12` 或 `Cmd+Option+I` (Mac)
   - 或右键点击页面 → 选择"检查"

2. **切换到移动设备视图**
   - 点击工具栏中的设备图标（📱）
   - 或按 `Cmd+Shift+M` (Mac) / `Ctrl+Shift+M` (Windows)

3. **选择设备预设**
   - iPhone 12 Pro / iPhone 13 Pro
   - Pixel 5 / Pixel 6
   - iPad Pro
   - 或自定义尺寸

4. **刷新页面**查看移动端效果

## 方法二：在真实手机上运行

### iOS 设备（iPhone/iPad）

1. **确保 Mac 上已安装 Xcode**
   ```bash
   xcode-select --install
   ```

2. **连接 iPhone/iPad 到 Mac**
   - 使用 USB 线连接
   - 在设备上信任此电脑

3. **在 Xcode 中信任设备**
   - 打开 Xcode
   - 选择 Window → Devices and Simulators
   - 选择您的设备并点击 "Trust"

4. **运行应用**
   ```bash
   flutter devices  # 查看设备列表
   flutter run -d <device-id>  # 运行到设备
   ```

### Android 设备

1. **启用开发者选项**
   - 设置 → 关于手机 → 连续点击"版本号"7次

2. **启用 USB 调试**
   - 设置 → 开发者选项 → 启用"USB 调试"

3. **连接设备到电脑**
   - 使用 USB 线连接
   - 在手机上允许 USB 调试

4. **运行应用**
   ```bash
   flutter devices  # 查看设备列表
   flutter run -d <device-id>  # 运行到设备
   ```

## 方法三：使用模拟器

### iOS 模拟器（推荐，macOS 专用）

1. **安装 Xcode**
   ```bash
   # 从 App Store 安装 Xcode
   ```

2. **启动 iOS 模拟器**
   ```bash
   open -a Simulator
   # 或
   xcrun simctl list devices  # 查看可用设备
   xcrun simctl boot "iPhone 14 Pro"  # 启动特定设备
   ```

3. **运行应用**
   ```bash
   flutter run
   ```

### Android 模拟器

1. **安装 Android Studio**
   - 下载并安装 Android Studio
   - 打开 Android Studio → SDK Manager → 安装 Android SDK

2. **创建 AVD（Android Virtual Device）**
   - Android Studio → Tools → AVD Manager
   - 点击 "Create Virtual Device"
   - 选择设备型号和系统镜像

3. **启动模拟器并运行**
   ```bash
   flutter emulators --launch <emulator-id>
   flutter run
   ```

## 方法四：使用 Flutter Web（移动浏览器）

1. **运行 Web 版本**
   ```bash
   flutter run -d chrome --web-renderer html
   ```

2. **在手机浏览器中访问**
   - 查看终端输出的 URL（通常是 `http://localhost:xxxxx`）
   - 确保手机和电脑在同一网络
   - 在手机浏览器中输入电脑的 IP 地址和端口

   ```bash
   # 查看电脑 IP 地址
   ifconfig | grep "inet "  # macOS/Linux
   ipconfig  # Windows
   ```

3. **访问应用**
   - 在手机浏览器中输入：`http://<电脑IP>:<端口>`
   - 例如：`http://192.168.1.100:50000`

## 故障排除

### 设备未识别
```bash
flutter doctor -v  # 检查 Flutter 环境
adb devices  # Android 设备
xcrun simctl list devices  # iOS 设备
```

### 端口被占用
```bash
lsof -ti:50000 | xargs kill -9  # 杀死占用端口的进程
```

### 网络连接问题
- 确保手机和电脑在同一 Wi-Fi 网络
- 检查防火墙设置
- 尝试使用 `--web-port` 指定端口
